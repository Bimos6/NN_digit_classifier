# MNIST Digit Classifier

Простой учебный классификатор рукописных цифр из датасета MNIST на нейронной сети, реализованной с нуля на Python с использованием NumPy, SciPy и Matplotlib.

Проект демонстрирует:
- прямое распространение сигнала;
- обучение методом обратного распространения ошибки;
- оценку качества на тестовой выборке;
- визуализацию «восстановленного» изображения цифры через `backquery`.

## Формат данных

Файлы `mnist_train_1000.csv` и `mnist_test_100.csv` должны находиться в папке `mnist_data/`.

Каждая строка CSV содержит:
```
label,pixel_0,pixel_1,...,pixel_783
```
где:
- `label` — правильная цифра от `0` до `9`;
- `pixel_0 ... pixel_783` — значения яркости пикселей изображения `28x28` в диапазоне `0–255`.

## Запуск

Из корня репозитория:
```bash
python main.py
```
Скрипт:
1. создаёт нейронную сеть `784 → 100 → 10`;
2. обучает её на `mnist_train_1000.csv` в течение `5` эпох;
3. тестирует на `mnist_test_100.csv`;
4. выводит долю правильных ответов;
5. строит изображение цифры `0`, восстановленное через `backquery`.

Пример вывода:
```
perfomance =  0.85
[0.99 0.01 0.01 0.01 0.01 0.01 0.01 0.01 0.01 0.01]
```
Точность зависит от данных, случайной инициализации весов и количества эпох.

## Параметры сети

В `main.py` заданы следующие параметры:

input_nodes = 784
hidden_nodes = 100
output_nodes = 10
learning_rate = 0.1
epochs = 5

Их можно изменить для экспериментов:
- увеличить `hidden_nodes` — больше ёмкость сети;
- увеличить `epochs` — больше эпох обучения;
- изменить `learning_rate` — скорость обучения.

## Как это работает

Нейронная сеть состоит из трёх слоёв:

1. Входной слой — 784 нейрона, по одному на каждый пиксель изображения `28x28`.
2. Скрытый слой — 100 нейронов с сигмоидной функцией активации.
3. Выходной слой — 10 нейронов, соответствующих цифрам `0–9`.

Обучение выполняется методом обратного распространения ошибки. Целевые значения формируются как `0.01` для всех классов и `0.99` для правильного класса.

## Визуализация `backquery`

Метод `backquery` пытается восстановить входное изображение по желаемому выходному вектору. В данном проекте он используется для визуализации того, как сеть «представляет» цифру `0`.

Примечание: в текущей реализации `inverse_activation_function` задана как `scipy.special.expit`, поэтому `backquery` является учебной демонстрацией, а не строго обратным преобразованием.
